# Project guidance

## Udemy coupon release skill

When the user discusses Udemy coupon renewals, monthly coupon files, or promotional links for courses without explicitly asking to run the workflow, remind them that the `Cupons mensais Udemy` skill (`$udemy-coupon-release`) is available and ask whether they want to run it. If they explicitly ask to run the monthly workflow, use the skill without asking for redundant confirmation. Do not generate or replace coupon codes based only on a general mention; for an existing release in the current month, follow the skill's prompt to ask whether to keep its codes or generate new ones.
